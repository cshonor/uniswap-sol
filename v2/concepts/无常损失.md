# Uniswap V2 无常损失详解

本文档详细说明 Uniswap V2 中的无常损失（Impermanent Loss）概念、计算方式和应对策略。

## 📋 概述

**无常损失（Impermanent Loss）** 是指流动性提供者（LP）在提供流动性时，由于代币价格变化而导致的潜在损失。这种损失是"无常"的，因为如果价格回到初始状态，损失就会消失。

---

## 🎯 什么是无常损失？

### 定义

无常损失是指：**持有代币 vs 提供流动性** 之间的价值差异。

- **持有代币**：如果 LP 不提供流动性，而是直接持有代币
- **提供流动性**：LP 将代币存入流动性池

当价格发生变化时，这两种方式的价值会产生差异，这个差异就是无常损失。

### 为什么会有无常损失？

由于恒定乘积公式 `x * y = k`，当价格变化时：
- 池子会自动调整代币比例
- 价格上升的代币会被卖出
- 价格下降的代币会被买入

这导致 LP 持有的代币比例发生变化，产生损失。

---

## 📊 无常损失计算

### 公式

**无常损失百分比：**

```
IL = 2 * sqrt(price_ratio) / (1 + price_ratio) - 1
```

其中：
- `price_ratio = 新价格 / 初始价格`

### 计算示例 1：DAI/ETH 池子（ETH 价格上涨）

**初始状态：**
- 初始 LP：100 DAI / 1 ETH
- 初始价格：`PE = y/x = 100 DAI / 1 ETH = 100 DAI/ETH`
- 初始总价值（以 DAI 计价）：`100 DAI + 1 ETH × 100 DAI/ETH = 200 DAI`
- 恒定乘积：`k = x × y = 100 × 1 = 100`

**价格变化：ETH 价格上涨到 120 DAI/ETH**

**恒定乘积公式调整：**
```
x × y = k
100 × 1 = 120 × 0.83
```

**新储备量计算：**
- 新价格：`PE = 120 / 0.83 = 144.58 DAI/ETH`
- 新储备量：`x = 120 DAI`, `y = 0.83 ETH`
- 验证：`120 × 0.83 = 99.6 ≈ 100` ✓

**如果提供流动性（LP 池子中的价值）：**
- LP 持有：`120 DAI + 0.83 ETH`
- 以新价格计算：`120 DAI + 0.83 ETH × 144.58 DAI/ETH = 120 + 120 = 240 DAI`

**如果持有代币（不提供流动性）：**
- 持有：`100 DAI + 1 ETH`
- 以新价格计算：`100 DAI + 1 ETH × 144.58 DAI/ETH = 100 + 144.58 = 244.58 DAI`

**无常损失：**
- 损失：`244.58 - 240 = 4.58 DAI`
- 损失率：`4.58 / 244.58 = 1.87%`

**关键观察：**
- ✅ ETH 价格上涨，但 LP 持有的 ETH 数量减少（从 1 ETH 到 0.83 ETH）
- ✅ 池子自动卖出 ETH，买入 DAI（因为 ETH 价格上涨）
- ✅ LP 错过了 ETH 价格上涨的收益

### 计算示例 2：DAI/ETH 池子（ETH 价格下跌）

**初始状态（t₀）：**
- 初始 LP：100 DAI : 1 ETH
- 初始价格：`PE = 100 DAI / 1 ETH = 100 DAI/ETH`
- 初始总价值（以 DAI 计价）：`t₀ = 100 DAI + 1 ETH × 100 DAI/ETH = 200 DAI`
- 恒定乘积：`k = x × y = 100 × 1 = 100`

**价格变化：ETH 价格下跌**

**恒定乘积公式调整：**
```
x · y = k
100 × 1 = 80 × 1.25 = 100
```

**新储备量计算：**
- 新储备量：`x = 80 DAI`, `y = 1.25 ETH`
- 新价格：`PE = 80 / 1.25 = 64 DAI/ETH`
- 验证：`80 × 1.25 = 100` ✓

**如果提供流动性（池子中的价值 U₁）：**
- LP 持有：`80 DAI + 1.25 ETH`
- 以新价格计算：`U₁ = 80 DAI + 1.25 ETH × 64 DAI/ETH = 80 + 80 = 160 DAI`

**如果持有代币（不提供流动性 U_hodl）：**
- 持有：`100 DAI + 1 ETH`
- 以新价格计算：`U_hodl = 100 DAI + 1 ETH × 64 DAI/ETH = 100 + 64 = 164 DAI`

**无常损失：**
- 损失：`V_hodl - V_pool = 164 - 160 = 4 DAI`
- 损失率：`4 / 164 = 2.44%`

**关键观察：**
- ✅ ETH 价格下跌，但 LP 持有的 ETH 数量增加（从 1 ETH 到 1.25 ETH）
- ✅ 池子自动买入 ETH，卖出 DAI（因为 ETH 价格下跌）
- ✅ LP 持有了更多贬值的 ETH，产生了损失

**对比涨价和降价：**

| 情况 | ETH 价格变化 | ETH 数量变化 | 池子价值 | 持有价值 | 无常损失 |
|------|------------|------------|---------|---------|---------|
| 涨价 | 100 → 144.58 DAI/ETH | 1 → 0.83 ETH | 240 DAI | 244.58 DAI | 4.58 DAI |
| 降价 | 100 → 64 DAI/ETH | 1 → 1.25 ETH | 160 DAI | 164 DAI | 4 DAI |

**重要理解：**
- ✅ **无论价格上涨还是下跌，都会有无常损失**
- ✅ **涨价时**：ETH 数量减少，错过上涨收益
- ✅ **降价时**：ETH 数量增加，持有更多贬值资产
- ✅ **损失是对称的**：相同幅度的涨跌，损失相近

### 计算示例 3：ETH/USDT 池子（ETH 价格上涨 2 倍）

**初始状态：**
- 价格：1 ETH = 2000 USDT
- LP 提供：1 ETH + 2000 USDT
- 总价值：4000 USDT
- 恒定乘积：`k = 1 × 2000 = 2000`

**价格变化：1 ETH = 4000 USDT（价格上涨 2 倍）**

**新储备量计算：**
```
x × y = k = 2000
y / x = 4000（新价格）

解得：
x = sqrt(2000 / 4000) = 0.707 ETH
y = sqrt(2000 × 4000) = 2828 USDT
```

**如果持有代币：**
- 价值：1 ETH + 2000 USDT = 4000 + 2000 = 6000 USDT

**如果提供流动性：**
- 池子自动调整：约 0.707 ETH + 2828 USDT
- 价值：0.707 × 4000 + 2828 = 2828 + 2828 = 5656 USDT

**无常损失：**
- 损失：6000 - 5656 = 344 USDT
- 损失率：344 / 6000 = 5.72%

### 不同价格变化下的无常损失

| 价格变化 | 价格比率 | 无常损失 |
|---------|---------|---------|
| -50% | 0.5 | -5.72% |
| -25% | 0.75 | -1.25% |
| 0% | 1.0 | 0% |
| +25% | 1.25 | -1.25% |
| +50% | 1.5 | -5.72% |
| +100% | 2.0 | -5.72% |
| +200% | 3.0 | -13.40% |
| +500% | 6.0 | -25.46% |

**关键观察：**
- 价格变化越大，无常损失越大
- 无论价格上涨还是下跌，都会有损失
- 损失是对称的（相同幅度的涨跌，损失相同）

## 🔍 无常损失的原理

### 恒定乘积公式的影响

**初始状态：**
```
x * y = k
1 ETH * 2000 USDT = 2000
```

**价格变化后（1 ETH = 4000 USDT）：**
```
新储备量需要满足：
- 价格 = reserve1 / reserve0 = 4000
- 乘积 = reserve0 * reserve1 = 2000

解得：
reserve0 = sqrt(2000 / 4000) = 0.707 ETH
reserve1 = sqrt(2000 * 4000) = 2828 USDT
```

**结果：**
- ETH 数量减少：1 → 0.707（被卖出）
- USDT 数量增加：2000 → 2828（被买入）
- LP 持有的 ETH 减少了

### 为什么会有损失？

当 ETH 价格上涨时：
- **持有代币**：ETH 价值上升，总价值增加
- **提供流动性**：池子自动卖出 ETH，买入 USDT
- **结果**：LP 持有的 ETH 减少，错过了价格上涨的收益

## 💡 实际案例

### 案例 1：ETH/USDT 池子

**初始：**
- 提供：10 ETH + 20,000 USDT
- 价格：1 ETH = 2000 USDT
- 总价值：40,000 USDT

**ETH 价格上涨到 3000 USDT：**

**持有代币：**
- 价值：10 × 3000 + 20,000 = 50,000 USDT

**提供流动性：**
- 池子调整：约 8.16 ETH + 24,494 USDT
- 价值：8.16 × 3000 + 24,494 = 48,974 USDT

**无常损失：**
- 损失：50,000 - 48,974 = 1,026 USDT
- 损失率：1,026 / 50,000 = 2.05%

### 案例 2：稳定币池子（USDC/USDT）

**特点：**
- 价格变化小
- 无常损失小
- 主要收益来自手续费

**初始：**
- 提供：10,000 USDC + 10,000 USDT
- 价格：1 USDC = 1 USDT

**价格变化到 1.01 USDT/USDC：**

**持有代币：**
- 价值：10,000 × 1.01 + 10,000 = 20,100 USDT

**提供流动性：**
- 池子调整：约 10,050 USDC + 9,950 USDT
- 价值：10,050 × 1.01 + 9,950 = 20,100.5 USDT

**无常损失：**
- 损失：20,100 - 20,100.5 = -0.5 USDT（几乎为零）

## 🛡️ 应对策略

### 1. 选择稳定币对

- 稳定币对价格变化小
- 无常损失最小
- 主要收益来自手续费

### 2. 选择相关性高的代币对

- 相关性高的代币价格变化方向一致
- 无常损失相对较小
- 例如：ETH/WETH、WBTC/BTC

### 3. 长期持有

- 无常损失是"无常"的
- 如果价格回到初始状态，损失消失
- 长期持有可以等待价格回归

### 4. 手续费收益覆盖

- 如果手续费收益 > 无常损失，仍然盈利
- 高交易量的池子手续费收益高
- 需要计算总收益（手续费 - 无常损失）

### 5. 使用对冲策略

- 在中心化交易所做空
- 使用衍生品对冲
- 降低价格风险

---

## 📈 总收益计算

### 公式

```
总收益 = 手续费收益 - 无常损失
```

### 示例

**场景：ETH/USDT 池子，ETH 价格上涨 50%**

**无常损失：**
- 损失：-5.72%

**手续费收益：**
- 假设年化手续费：15%
- 持有时间：1 个月
- 手续费收益：15% / 12 = 1.25%

**总收益：**
- 总收益：1.25% - 5.72% = -4.47%（亏损）

**如果手续费收益更高：**
- 年化手续费：30%
- 手续费收益：30% / 12 = 2.5%
- 总收益：2.5% - 5.72% = -3.22%（仍然亏损）

**结论：**
- 需要足够高的手续费收益才能覆盖无常损失
- 价格波动越大，需要的手续费收益越高

---

## ⚠️ 重要注意事项

### 1. 无常损失是永久性的

- 虽然叫"无常"，但如果价格不回归，损失是永久的
- 只有在价格回到初始状态时，损失才会消失

### 2. 手续费收益需要时间

- 手续费是逐步累积的
- 需要持有足够长时间才能获得收益

### 3. 价格波动风险

- 价格波动越大，无常损失越大
- 需要评估代币的波动性

### 4. 机会成本

- 提供流动性意味着放弃了直接持有代币的机会
- 如果代币大幅上涨，可能错过收益

## 🎓 总结

无常损失是流动性提供者必须了解的重要概念：

1. **定义**：持有代币 vs 提供流动性的价值差异
2. **原因**：恒定乘积公式导致代币比例自动调整
3. **计算**：价格变化越大，损失越大
4. **应对**：选择稳定币对、长期持有、手续费收益覆盖
5. **风险**：需要评估总收益（手续费 - 无常损失）

理解无常损失有助于做出更好的流动性提供决策。
